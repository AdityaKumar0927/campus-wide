# Compliance pack

What a university security or privacy office usually asks for, in one folder.

| Document | What it answers |
|---|---|
| [HECVAT.md](HECVAT.md) | The standard higher-education vendor questionnaire, Full 4.1.5 structure |
| [data-map.md](data-map.md) | Every category of personal data: where it lives, who reads it, when it goes |
| [security-verification.md](security-verification.md) | How each security control is implemented and how it was checked |
| [incident-response.md](incident-response.md) | Roles, severities, and the steps for a breach |

The member-facing documents (privacy, terms, guidelines, DSA contact, subprocessors, the DPA template)
live in `content/policies/` and are published at `/policies`.
